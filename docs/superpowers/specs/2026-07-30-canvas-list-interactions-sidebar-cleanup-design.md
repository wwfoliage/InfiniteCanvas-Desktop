# 画布列表交互修复与侧栏清理设计

## 背景

当前白天模式下有三项已确认的问题：

1. 在画布列表的空白区域按住鼠标拖动画布时，Microsoft Edge 偶尔会进入原生文字拖拽搜索，并搜索“新建画布”等页面文本。
2. 在画布列表空白位置双击新建画布时，“新建画布”浮层与鼠标位置存在明显偏移；界面缩放后偏移更明显。
3. 主侧栏左下角的项目主页、更新入口、版本信息、作者信息与社交链接不再需要。

工作流导入入口已经存在于普通画布和智能画布的“工作流”面板中，本次不调整工作流导入导出功能。

## 目标

- 画布列表空白区域拖动只执行列表平移，不触发浏览器原生文字选择、拖拽或搜索。
- 双击新建浮层在鼠标附近出现，在各种界面缩放比例下保持准确，并且不会超出可视区域。
- 删除侧栏左下角用户指定的外部项目、更新和作者信息区域。
- 保留 API 设置、更多设置、主题、语言和工作流设置。
- 修改范围尽量局部，不改变普通画布与智能画布内部的节点交互。

## 非目标

- 不修改普通画布或智能画布中的画布拖拽逻辑。
- 不修改工作流 JSON/ZIP 的导入导出逻辑。
- 不删除后端更新接口或更新弹窗代码，避免扩大变更范围；仅移除侧栏入口并停止页面启动时的自动更新检查。
- 不改变画布列表卡片的点击、菜单、拖动排序或输入框文字选择。

## 设计

### 1. 阻止 Edge 原生拖拽搜索

在 `static/js/canvas-list.js` 的画布列表平移入口中，仅当满足以下条件时调用 `preventDefault()`：

- 鼠标左键；
- 目标位于画布列表空白区域；
- 目标不是画布卡片、新建卡片、卡片菜单、按钮、输入控件或可编辑内容。

同时在画布列表容器上处理 `dragstart` 与 `selectstart`，对非交互区域阻止浏览器原生行为。输入框、文本域、下拉框和 `contenteditable` 内容仍允许正常选择与编辑。

该处理严格限定在画布列表容器，不影响其他页面。

### 2. 修正界面缩放后的坐标换算

现有 `screenToWorld()` 只使用 `getBoundingClientRect()` 左上角、视口平移与画布缩放，没有考虑主界面的 CSS `zoom`/显示缩放。

新的换算先计算画布元素的显示比例：

- `displayScaleX = rect.width / board.clientWidth`
- `displayScaleY = rect.height / board.clientHeight`

然后把浏览器客户区坐标还原为画布本地 CSS 坐标，再应用画布列表自身的平移和缩放。显示比例无效时回退为 `1`。

由于画布卡片拖动也复用 `screenToWorld()`，该修正会同步消除界面缩放下的卡片拖动偏差。

### 3. 新建画布浮层靠近鼠标并限制边界

双击空白区域时：

- 浮层默认放在鼠标右下约 10 像素处；
- 创建浮层后根据其实际尺寸和当前可视画布边界进行校正；
- 靠近右侧或底部时向内移动，始终保留少量边距；
- 左侧和顶部同样设置最小安全边距。

浮层仍保存在画布世界坐标系中，因此列表继续缩放或平移时行为与现有卡片一致。

### 4. 删除侧栏左下角内容

从 `static/index.html` 删除：

- “项目主页”按钮；
- “一键更新/更新到版本”按钮；
- 版本徽标；
- `DX`、作者名 `wuli大雄`；
- 哔哩哔哩、小红书、YouTube、X 等社交链接。

保留 `side-actions` 中的 API 设置与更多设置分组。删除页面加载时无入口可见的自动 `checkForUpdates()` 调用，避免继续进行无意义的联网检查。

现有更新函数、更新弹窗和后端接口暂不删除，以降低回归风险并保持未来恢复入口的可能性。

## 验收标准

1. 在画布列表空白处连续拖动，不出现 Edge 的“松开鼠标以搜索文本”提示。
2. 卡片、按钮和输入框仍可正常点击；输入框内文字仍可选择。
3. 在 100%、常用界面缩放比例以及浏览器缩放环境下，双击浮层出现在鼠标附近。
4. 在画布四条边附近双击，浮层不会超出可视区域。
5. 界面缩放后拖动画布列表卡片，卡片继续跟随鼠标。
6. 左下角指定内容全部消失，API 设置与更多设置仍存在并可用。
7. 普通画布、智能画布及工作流导入导出行为不发生变化。

## 测试策略

- 为 `canvas-list.js` 增加静态回归测试，检查坐标缩放修正、原生拖拽抑制和浮层边界校正逻辑。
- 为 `static/index.html` 增加静态回归测试，确认被删除入口不再存在、保留入口仍存在、自动更新检查不再在启动阶段执行。
- 运行现有项目测试，重点覆盖暖米灰主题、Seedance 480p 与 MediaKit，避免破坏已有定制。
- 在本地浏览器手动验证画布列表拖动、双击四角创建与侧栏布局。
