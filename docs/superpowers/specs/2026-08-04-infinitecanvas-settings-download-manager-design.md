# InfiniteCanvas 设置中心与桌面下载管理器设计

## 背景

InfiniteCanvas 桌面版使用 PyWebView 5.4 和 EdgeChromium 承载本地 FastAPI 页面。当前前端通过 `<a download>`、临时 Blob URL 等浏览器机制下载图片、视频、素材、工作流、画布 JSON 和 ZIP。PyWebView 的 `ALLOW_DOWNLOADS` 默认值为 `False`，`desktop_app.py` 没有启用它，因此 Windows 下载事件会被直接取消，界面也无法得到可靠的成功或失败结果。

当前设置入口同时分散在左侧栏的 API 设置、主题、语言和工作流设置按钮中。“更多设置”还是可展开的小菜单，无法承载下载目录、存储占用、缓存和更新信息。

## 已确认决策

- 左侧主导航只保留一个“设置”入口。
- 设置使用完整内容页面，不使用弹窗或悬浮菜单。
- 设置页面内部使用固定二级导航和右侧内容区。
- 第一版包含下载、界面、语言、API、工作流、存储与缓存、关于与更新七项。
- 默认下载目录为系统“下载”目录下的 `InfiniteCanvas` 文件夹，用户可修改或恢复默认。
- 下载直接保存，不弹出“另存为”。
- 同名文件自动追加序号，永不覆盖。
- 文件按类型整理的开关默认开启。
- 缓存清理只处理可重新生成的预览缓存和临时文件。
- 更新继续由用户手动检查和执行。

## 目标

1. 修复 EXE 中所有现有下载入口，确保下载真实写入磁盘并能报告结果。
2. 提供统一下载目录、类型分类、同名文件处理和完成提醒。
3. 把现有 API、主题、语言和工作流设置收拢到同一个设置中心。
4. 增加存储占用、受限缓存清理、版本、更新和日志入口。
5. 保持普通浏览器开发模式可用，保持现有用户数据和敏感配置不变。

## 非目标

- 不实现云端同步或多设备设置同步。
- 不允许网页传入任意本地路径进行读取或覆盖。
- 不把 API 密钥迁入普通设置文件。
- 不提供项目、素材、工作流、对话或 API 配置的一键删除。
- 不自动下载或安装更新。
- 不修改现有项目数据格式、画布格式或工作流格式。

## 设置中心界面

点击主侧栏底部的“设置”后，当前内容区切换到设置中心。主侧栏继续存在；内容区内部由固定宽度的二级导航、细分隔线和右侧内容组成。页面与现有 InfiniteCanvas 浅色/深色主题保持一致，不增加悬浮容器或卡片套卡片。

二级菜单顺序固定为：

1. 下载设置
2. 界面设置
3. 语言设置
4. API 设置
5. 工作流设置
6. 存储与缓存
7. 关于与更新

设置中心记住最后访问的分类。主窗口最小宽度为 1024 像素；空间不足时缩窄二级导航和内容边距，表单行改为上下排列，不产生文字遮挡或横向溢出。

现有 API 和工作流页面继续复用成熟业务逻辑，但增加嵌入模式：去掉重复的页面外框、背景和过大留白，使它们成为右侧内容区的一部分。原左侧栏的独立 API 按钮、主题按钮、语言按钮和“更多设置”折叠组全部移除。

## 七类设置

### 下载设置

- 下载目录：显示解析后的绝对路径，支持“更改”和“恢复默认”。
- 按类型整理：默认开启。
- 同名文件：固定为“自动追加序号”，第一版不提供覆盖模式。
- 完成提醒：默认开启；成功后显示文件名和保存位置，并提供“打开文件夹”。

开启分类后使用以下中文子目录：

- 图片
- 视频
- 音频
- 工作流
- 画布导出
- 其他

### 界面设置

- 颜色模式：跟随系统、浅色、深色。
- 界面缩放：自动、80%、90%、100%、110%、125%。

“跟随系统”使用 `prefers-color-scheme` 并监听系统变化。缩放只改变按钮、文字、侧栏和面板的 UI 比例，不改变画布数据、生成尺寸或下载分辨率。设置立即同步到所有已加载的 iframe，无需重启。

### 语言设置

提供中文和英文。切换后主页面、设置中心和所有已加载页面立即同步，保留现有 i18n 字典和消息广播机制。

### API 设置

保留现有 API 平台、密钥、接口地址、模型拉取、模型配置和连通性能力。API 密钥仍写入现有受保护配置，不进入普通应用设置 JSON。

### 工作流设置

保留现有 ComfyUI 后端地址、工作流导入、字段配置、画布节点预览和保存能力，只调整外层布局以适应设置中心。

### 存储与缓存

显示项目数据、素材、媒体预览缓存和日志目录及各自占用空间，提供受限的“打开目录”操作。

允许清理的内容只有：

- 可重新生成的 `media_previews` 内容。
- 下载管理器专用临时目录中的未完成文件。
- 下载管理器专用临时根目录中的登记文件。

以下内容必须始终排除：画布、项目、素材、素材库索引、提示词、工作流、对话、API 配置、日志和 WebView 登录数据。清理前显示范围和预计大小并要求确认，完成后重新计算占用。

### 关于与更新

显示当前版本、更新说明、手动检查更新、下载源网络检测和日志目录入口。复用现有更新与回滚逻辑，但不在后台自动下载或安装。

## 设置存储

新增版本化的普通设置文件：

`%LOCALAPPDATA%\InfiniteCanvas\data\app_settings.json`

文件结构：

```json
{
  "schema_version": 1,
  "downloads": {
    "directory": "",
    "categorize": true,
    "notify": true
  },
  "appearance": {
    "theme": "system",
    "scale": "auto"
  },
  "language": "zh"
}
```

空下载目录表示使用系统默认值。服务端负责默认值、字段白名单、枚举校验和向前兼容；未知字段不参与运行。写入使用临时文件加原子替换，避免异常退出留下半个 JSON。

现有 `studio_theme`、`canvas_theme`、`studio_ui_scale_mode` 和 `studio_lang` 在首次升级时迁入普通设置文件。为避免首屏主题闪烁，界面设置仍同步一份无敏感内容的 localStorage 快速缓存；JSON 是桌面版的最终来源。

API 密钥、API 服务商、工作流和 MediaKit 配置继续使用现有文件，不复制到 `app_settings.json`。

## 下载管理器

### 前端入口

新增共享的 `StudioDownloads` 前端模块。画布、智能画布、素材库、生成页面、工作流导出和画布导出均通过该模块下载，不再各自创建临时 `<a>` 后假定成功。

调用参数只包含：

- 受支持的来源 URL 或浏览器生成的 Blob。
- 请求文件名。
- 文件分类。

桌面模式调用本地下载 API；普通浏览器开发模式在 API 不可用时回退为标准浏览器下载。

### 服务端入口

下载服务提供两个边界明确的入口：

- 保存 URL：处理应用本地 URL 和允许的 HTTP/HTTPS 远程 URL。
- 保存上传内容：处理浏览器生成的 JSON、ZIP、编辑结果和其他 Blob。

本地 URL 只能通过现有安全解析逻辑映射到 `output`、`assets` 等已登记资源根目录。服务不得接受浏览器传入的任意本地文件路径。

远程文件继续流式读取，不把大视频完整载入内存。浏览器生成内容使用有限大小的流式上传。返回结果包含最终文件名、分类、绝对保存路径和可展示的错误码。

### 文件落盘

1. 校验并清理请求文件名，保留可用扩展名。
2. 根据明确分类或 MIME/扩展名确定子目录。
3. 创建配置的下载根目录和分类目录。
4. 在目标目录创建唯一的 `.part` 临时文件。
5. 流式写入并刷新文件。
6. 同名时选择 `name (1).ext`、`name (2).ext`，不覆盖已有文件。
7. 使用原子改名提交正式文件。
8. 返回真实保存结果后，前端才显示成功。

取消、网络错误、权限不足、磁盘空间不足或目录不可用时删除本次临时文件，并返回可读错误。配置目录被手动删除时自动重建；无法重建时不静默改存其他位置。

### PyWebView 原生桥接

桌面窗口暴露最小化 `DesktopApi`：

- 选择下载文件夹。
- 打开已登记的下载、数据、缓存或日志目录。

目录打开操作只接受固定目录类型或已经校验的当前下载目录，不接受网页提供的任意路径。iframe 通过同源 `postMessage` 请求顶层页面调用原生桥接，避免每个子页面重复依赖 PyWebView 注入细节。

同时启用 PyWebView 的 `ALLOW_DOWNLOADS` 作为尚未迁移入口的兼容兜底；所有已知产品下载按钮必须使用统一下载管理器，以满足直接保存和分类规则。

## API 与模块边界

实现时优先新增小模块，避免继续扩大 `main.py` 和 `index.html`：

- `app_settings.py`：设置默认值、规范化、迁移和原子保存。
- `download_manager.py`：目录解析、分类、唯一命名、流式写入和结果模型。
- `desktop_app.py`：`DesktopApi` 与 PyWebView 启动配置。
- `static/settings.html`、`static/css/settings.css`、`static/js/settings.js`：设置中心。
- `static/js/downloads.js`：共享下载前端。

FastAPI 路由保留在 `main.py` 中以匹配现有项目结构，但路由只做请求解析和错误映射，核心逻辑放到上述模块。

## 安全与隐私

- 下载目录必须是绝对目录，不能是文件路径；保存目标始终由服务端组合。
- 文件名去除路径分隔符、控制字符、Windows 保留名和尾随点/空格。
- 远程下载只允许 HTTP/HTTPS，并沿用现有 URL 重写与超时限制。
- 不在日志或普通设置中写入 API 密钥、请求头、Cookie 或提示词正文。
- 缓存清理使用固定允许根目录，清理前重新解析绝对路径并拒绝越界。
- 打开目录的原生操作使用白名单，不暴露通用命令执行能力。

## 兼容与迁移

- 已有主题、语言和缩放偏好自动迁移，用户无需重新设置。
- 现有 API、工作流、素材、画布和项目数据不迁移、不重写。
- 现有下载按钮的文件名尽量保持不变，仅由统一模块负责清理、分类和冲突处理。
- 安装包升级继续保留 `%LOCALAPPDATA%\InfiniteCanvas`，因此下载和界面设置随版本更新保留。
- 普通浏览器运行仍能使用原下载机制，不要求存在 `window.pywebview`。

## 测试策略

### 单元测试

- 设置默认值、旧 localStorage 值迁移所需的规范化映射、非法值回退和原子写入。
- 下载目录分类、中文文件名、Windows 保留名、无扩展名和同名序号。
- 写入失败时清理 `.part`，不覆盖已有文件。
- 缓存清理允许列表和越界拒绝。
- `DesktopApi` 文件夹选择、取消选择和目录白名单。

### API 与静态结构测试

- URL 下载、Blob 上传、远程失败、无权限目录和批量 ZIP。
- 设置中心七个菜单、单一主设置入口、旧独立设置按钮移除。
- API/工作流嵌入模式、主题/语言/缩放消息同步。
- 所有现有下载按钮接入共享模块，不遗留直接假定成功的 `<a download>` 路径。

### 桌面验收

使用真实 Windows 用户启动新构建的 EXE，确认：

- 只出现一个 PyWebView 桌面窗口，不打开浏览器或 CMD。
- 首次下载自动创建 `Downloads\InfiniteCanvas`。
- 图片、视频、音频、工作流、画布 JSON 和 ZIP 写入正确分类。
- 同名下载生成序号文件，旧文件哈希不变。
- 更改目录、恢复默认、打开文件夹和完成提醒有效。
- 跟随系统、浅色、深色、自动缩放和手动缩放有效。
- 中英文切换覆盖设置中心和嵌入页面。
- 清理缓存前后的项目、素材、工作流和 API 配置哈希不变。

## 完成标准

- EXE 中所有产品下载入口均能真实保存文件并报告最终路径。
- 下载目录、分类和完成提醒重启后保持。
- 左侧栏只保留一个设置入口，七个二级页面均可访问。
- API 和工作流功能未回归，主题、缩放和语言立即同步。
- 缓存清理无法触及用户项目和敏感配置。
- 自动化测试通过，桌面端按上述清单验收通过。
