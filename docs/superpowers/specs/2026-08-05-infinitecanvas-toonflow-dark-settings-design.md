# InfiniteCanvas Toonflow 风格深色设置界面设计

## 目标

将 InfiniteCanvas 设置界面的深色模式改为参考 Toonflow 的中性黑灰方案，消除当前蓝黑、黑绿和通用主题样式混用造成的突兀色块。设置页及其外围容器必须连续铺满，不再出现底部横条、外框或下载选项行颜色没有覆盖完整的情况。

本次同时恢复应用左下角设置入口原有的线框齿轮图标，并以 `2026.08.06` 发布新的完整 Windows 安装包。安装包继续同时支持新电脑首次安装和已有版本覆盖升级。

## 已确认的视觉方向

深色模式使用从 Toonflow 实际主题中提取的灰阶：

- 页面底色：`#181818`
- 主面板：`#242424`
- 输入框和按钮表面：`#2c2c2c`
- 悬停、选中和细分隔层：`#393939`
- 强边框和较高层级控件：`#4b4b4b`
- 主文字：`rgba(255, 255, 255, 0.9)`
- 次要文字：`rgba(255, 255, 255, 0.55)`
- 弱提示文字：`rgba(255, 255, 255, 0.35)`
- 开关开启轨道：`#717171`

选中菜单、分段控件和开关只使用中性灰阶，不使用绿色或蓝色作为大面积强调色。错误、危险操作等有明确语义的状态可以保留必要的红色，但不得成为页面主色。

界面沿用现有设置页的固定左侧二级导航，不改成 Toonflow 的悬浮弹窗。下载设置、界面设置、语言设置、API 设置、工作流设置、存储与缓存、关于与更新的栏目结构不变。

## 范围

本次修改包括：

1. 设置页深色主题变量和设置页专属组件样式。
2. 设置 iframe、设置宿主区域和滚动区域的连续背景覆盖。
3. 通用主题样式对设置行的错误覆盖隔离。
4. 设置入口的线框齿轮图标恢复。
5. 设置资源查询版本递增，避免旧 CSS 或 HTML 缓存继续显示旧配色。
6. 桌面与窄窗口布局验收。
7. `2026.08.06` 完整升级安装包构建、覆盖安装和发布材料生成。

本次不修改：

- 画布工作区、资源页和其他应用页面的现有配色；
- 设置项的数据结构、保存位置或业务行为；
- `E:\Toonflow` 中的任何文件；
- 自动更新机制，用户仍手动下载并运行更高版本的完整安装包；
- 已推送的 `v2026.08.05` 标签和对应构建内容。

## 样式架构

### 设置页主题变量

`static/css/settings.css` 继续作为设置页视觉样式的唯一主要所有者。现有 `--settings-*` 变量保持名称稳定，只替换深色模式的值并在需要时增加中性灰层级变量，避免把 Toonflow 的 TDesign 变量或组件依赖引入 InfiniteCanvas。

浅色模式保持现有暖灰方案，不随本次深色模式改动而重新设计。

### 通用样式隔离

`static/css/theme.css` 中存在多组通用 `.setting-row` 深色规则，会覆盖 `settings.css` 并把部分下载行染成蓝黑色。设置页需要用 `.settings-shell` 等设置页根作用域为行、分组、输入框和开关提供明确覆盖，使最终样式只由设置页变量控制。

不进行与本需求无关的全局主题重构。通用规则继续服务其他旧页面，设置页通过局部作用域隔离。

### 连续背景覆盖

以下层级在深色设置模式下使用同一基础底色 `#181818`：

- 设置 iframe 的 `html` 和 `body`；
- `.settings-shell`；
- 左侧设置导航；
- 右侧内容滚动区；
- 设置 iframe 宿主和设置页面所在的主舞台区域。

主面板色 `#242424` 只用于确实需要抬高层级的局部表面，不作为大片横条。下载目录行、开关行和普通选项行保持透明背景，通过细分隔线组织信息。输入框、目录按钮和命令按钮使用 `#2c2c2c`，悬停时使用 `#393939`。

设置 iframe 和宿主必须填满可用区域，不能依赖与内容高度相关的底部留白。滚动条所在区域也必须继承相同背景，窗口放大、缩小或滚动到底部时不得露出蓝黑色或其他底色。

## 组件设计

### 二级导航

导航默认透明，文字和图标使用次要白色。悬停项使用 `#2c2c2c`，当前项固定使用 `#303030`，并将文字提升为主文字色。导航选中态不使用绿色、蓝色描边或彩色图标。

### 设置内容

标题、分组和普通设置行继续采用无卡片布局。分组之间使用 `#393939` 的单像素分隔线；组内较弱分隔线使用低透明度白色。页面不添加外层卡片，也不在设置行外包裹不同色的大面积矩形。

目录输出、输入框和按钮使用统一控件表面与边框。控件圆角保持现有紧凑桌面工具风格，不引入 Toonflow 的弹窗框架或悬浮菜单。

### 开关和分段控件

关闭开关使用中深灰轨道，开启开关使用 `#717171`，滑块使用白色。分段控件容器使用 `#2c2c2c`，当前项使用 `#4b4b4b`。颜色模式和界面缩放继续使用现有交互与保存逻辑，仅改变视觉表现。

### 设置入口图标

应用左下角真实的设置按钮恢复为原有线框齿轮 SVG。当前误用的链条图标不再作为设置入口。图标尺寸、描边和按钮交互状态沿用现有侧栏规范。

## 状态与数据流

主题偏好仍通过现有设置读写和 iframe 主题同步流程传递。系统、浅色、深色三种模式的选择规则不变，手动界面缩放和自动缩放规则不变。本次不新增设置字段，也不迁移用户数据。

切换到深色模式时，设置 iframe 根元素获得现有深色主题类并应用黑灰变量；切换到浅色模式时恢复现有浅色变量。设置 iframe 载入失败、主题消息尚未到达或页面首次渲染期间，宿主和 iframe 默认背景也不能出现明显异色闪烁。

## 缓存与兼容性

修改完成后递增 `settings.html`、`settings.css` 和设置 iframe 的查询版本。旧安装覆盖升级后必须加载新版资源，不依赖用户清理 WebView2 缓存。

设置页保持现有响应式边界：常规桌面窗口显示文字导航；窄窗口收起为图标导航。下载目录、长路径、中文和英文标签不得溢出或与开关重叠。

## 测试与验收

自动化或静态测试至少覆盖：

1. 深色设置变量包含已确认的 Toonflow 灰阶，不再包含旧黑绿色主色。
2. 设置页专属作用域覆盖通用 `.setting-row` 深色规则。
3. 设置 iframe 和宿主的背景、尺寸和缓存查询版本均已更新。
4. 真实设置入口使用齿轮图标，不再使用链条图标。
5. 版本号、安装器输出和发布清单统一为 `2026.08.06`。

浏览器或 PyWebView 视觉验收至少覆盖：

1. 常规桌面窗口下设置页从顶部到底部连续为中性黑灰，无蓝色横条、黑绿区域或未覆盖外框。
2. 下载目录、按类型整理、同名文件和完成提醒各行背景一致，只有控件表面略亮。
3. 导航、按钮、输入框、分段控件、开关和文字对比度清晰。
4. 在下载设置和界面设置之间切换后配色保持一致。
5. 窄窗口下无水平溢出，文字、目录控件和开关互不遮挡。
6. 左下角显示线框齿轮设置图标。
7. 浅色模式仍可用，且没有被深色设置专属规则污染。

安装包验收继续覆盖：

1. 无 InfiniteCanvas 的电脑可以直接首次安装。
2. 已安装 `2026.08.05` 的环境可以直接覆盖升级到 `2026.08.06`。
3. `%LOCALAPPDATA%\InfiniteCanvas` 中的画布、素材、API 配置、设置和下载配置在升级前后保持不变。
4. 启动后只出现 PyWebView 桌面窗口，不打开浏览器或 CMD，关闭后无残留进程。
5. 生成安装包、`SHA256SUMS.txt` 和 `release-manifest.json`，整理到 `E:\codex\发布安装包\InfiniteCanvas\2026.08.06`。

## 发布规则

本次发布创建新的 `v2026.08.06` 标签和 GitHub Release，不修改已推送的 `v2026.08.05`。旧的 `2026.08.05` Release 草稿如何处理属于独立发布操作，如需删除或放弃必须再次取得用户确认。

最终继续发布完整安装包，不制作依赖旧版本的差分补丁。用户只需运行新版安装程序即可升级，新电脑也使用同一个安装包首次安装。
