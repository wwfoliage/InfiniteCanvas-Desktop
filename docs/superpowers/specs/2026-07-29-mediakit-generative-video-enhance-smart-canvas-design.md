# 智能画布与普通画布 AI MediaKit 生成式画质增强设计

日期：2026-07-29

状态：智能画布与普通画布交互均已确认，等待书面设计审阅

范围：智能画布（Smart Canvas）与普通画布（Canvas）

## 1. 背景与目标

InfiniteCanvas 当前可以在智能画布和普通画布中生成、导入和连接视频，但没有一个可串接在视频节点后的通用云端画质增强节点。

本功能接入火山引擎 AI MediaKit 的“画质增强（大模型版）”，使用独立接口：

```text
POST https://mediakit.cn-beijing.volces.com/api/v1/tools/enhance-video-generative
```

用户需要在两种画布中得到符合各自节点规范的可视化流程：

```text
智能画布：原视频节点 → 生成式画质增强节点 → 增强结果视频节点
普通画布：视频来源节点 → MediaKit 画质增强节点 → Output 节点
```

连接本身不会产生费用。只有用户在增强节点中点击“开始增强”后才提交任务。原视频始终保留，增强后的视频放入新节点。

## 2. 已确认的产品决策

- 首版只接入 `enhance-video-generative`，不接入标准版、专业版或极速版接口。
- 智能画布严格复用智能画布现有节点、端口、连线、状态和结果节点规则。
- 普通画布使用独立的原生 Canvas 节点，严格复用普通画布现有节点头、端口、参数区、运行状态、失败重试和 Output 节点规则，不套用智能画布卡片样式。
- 两种画布共用同一套 MediaKit Key、保存目录、输入预检、任务查询和本地保存后端。
- 使用独立的 AI MediaKit API Key，不能复用火山方舟 Ark API Key。
- 默认参数：
  - 目标分辨率：`720p`
  - 码率档位：`medium`
  - 目标帧率：不传，保持原视频帧率
- 输入视频在提交前检查 SDR/HDR；明确检测为 HDR 时必须在提交前拦截。
- 任务成功后把远端临时结果下载到用户设置的本地目录，再写入结果节点。
- 保存目录支持继承全局“生成素材”目录，也支持单独设置自定义绝对路径。

## 3. 方案比较

### 3.1 直接调用 MediaKit REST API（采用）

由 FastAPI 后端保存 Key、上传本地视频、提交任务、查询状态和下载结果。

优点：

- 不增加 Node.js/CLI 运行依赖。
- Key 全程留在后端，不暴露给浏览器。
- 容易接入现有画布任务恢复和本地素材管理。
- 可以精确控制输入校验、输出保存和错误信息。

缺点：

- 需要自行维护 MediaKit 上传、提交、查询和下载流程。

### 3.2 通过官方 MediaKit CLI 调用

后端启动 `mediakit-cli` 子进程并解析输出。

优点：

- CLI 可代管本地文件上传和部分协议细节。

缺点：

- 每台部署电脑都要准备 Node.js 和 CLI。
- 子进程、版本兼容和输出解析会增加部署风险。
- 不利于给其他电脑分发少量替换文件。

### 3.3 合并进现有火山引擎 Ark 平台

把 MediaKit Key 和增强能力放进现有 `volcengine` Provider。

优点：

- 平台列表少一个入口。

缺点：

- Ark Key 与 MediaKit Key 来源、权限和服务地址不同，容易误填。
- Provider 模型生成逻辑与媒体后处理逻辑职责混杂。

因此采用 3.1，并在 API 设置中提供独立的 AI MediaKit 固定卡片。

## 4. 官方能力与约束

### 4.1 请求字段

首版前端只暴露官方体验页中的三个参数：

| UI | API 字段 | 允许值 | 默认值 |
|---|---|---|---|
| 目标分辨率 | `resolution` | `720p`、`1080p`、`2k` | `720p` |
| 码率档位 | `bitrate_level` | `low`、`medium`、`high` | `medium` |
| 目标帧率 | `fps` | 15–120 | 不传 |

目标帧率留空时，请求体中不出现 `fps`，由服务保持原视频帧率。

### 4.2 输入限制

- 支持常见视频格式：MP4、FLV、TS、AVI、MOV、WMV、MKV。
- 输入最高支持 1080p。
- 官方给出的尺寸范围：
  - 短边：360–1080
  - 长边：360–1920
- 仅支持 SDR 视频。

SDR 检测采用媒体元数据。明确出现以下信号时视为 HDR 并阻止提交：

- HDR10/PQ：`smpte2084`
- HLG：`arib-std-b67`
- Dolby Vision 标记

常见 BT.709/BT.601 视频按 SDR 处理。元数据未标记色彩传递函数时，界面显示“未检测到 HDR 标记”，允许继续交由 MediaKit 做最终校验，避免误伤普通 MP4。

### 4.3 异步结果

提交成功后返回远端 `task_id`。后端查询：

```text
GET https://mediakit.cn-beijing.volces.com/api/v1/tasks/{task_id}
```

任务终态：

- `completed`：读取 `result.video_url`
- `failed`：显示官方错误

未指定 VOD/TOS 输出位置时，`result.video_url` 是约 24 小时有效的临时地址，所以应用必须尽快下载到本地。

## 5. 智能画布节点设计

### 5.1 节点类型

新增节点类型：

```text
smart-video-enhance
```

节点使用与 Prompt/Loop 节点相同的面板体系：

- 相同的卡片背景、边框、圆角、阴影和毛玻璃效果
- 相同的亮色/暗色主题变量
- 相同的选中描边、拖动、缩放、删除和计时药丸
- 相同的左侧输入端口与右侧输出端口
- 相同的贝塞尔连线、悬停和删除规则

建议初始宽度为 340px，与 Loop 节点保持一致。节点高度由内容自动适配，仍允许使用现有右下角缩放手柄调整。

### 5.2 节点内容

从上到下排列：

1. 内部标题行
   - 图标：`wand-sparkles`
   - 标题：`生成式画质增强`
   - 状态：未连接 / 已就绪 / 提交中 / 处理中 / 已完成 / 失败
2. 上游视频预览
   - 复用 `.smart-node-input-thumbs`
   - 只有一个视频时直接显示缩略图
   - 上游节点包含多个视频时显示缩略图选择器，并把所选媒体索引持久化到增强节点
3. 目标分辨率
   - 三段按钮：720P / 1080P / 2K
4. 码率档位
   - 三段按钮：低码率 / 中码率 / 高码率
5. 目标帧率
   - 数字输入框，允许留空
   - 有值时限制为 15–120
   - 辅助文字：留空保持原帧率
6. 主操作按钮
   - 默认文字：`开始增强`
   - 运行时文字：`处理中`
   - 任务失败且允许重新提交时：`重新增强`

### 5.3 节点创建入口

提供两个入口：

1. 双击智能画布空白处，在现有创建菜单中增加“画质增强”卡片。
2. 选中单个视频后，在现有顶部浮动工具栏中增加“画质增强”快捷动作。

快捷动作会：

- 在视频节点右侧创建增强节点
- 自动建立 `视频节点 → 增强节点` 连接
- 保持增强节点选中

手动创建的增强节点可通过现有端口拖线连接。

### 5.4 连接规则

- 增强节点只接受包含视频素材的智能媒体节点作为输入。
- 最多允许一个上游输入节点。
- 图片、音频、Prompt、Loop 或 Group 若没有可用视频，不允许连接。
- 上游有多个视频时必须在节点中选中一个视频后才能运行。
- 节点右侧输出端口保留，可参与现有流程连线；自动创建结果时使用该端口建立连接。

### 5.5 开始按钮状态

以下条件全部满足才启用：

- 已连接一个可用视频
- 多视频输入时已选定具体视频
- MediaKit Key 已配置
- 保存目录有效且可写
- 参数合法
- 当前没有正在进行的增强任务

按钮禁用时，在节点内部给出最短且可操作的原因，例如：

- `请连接视频`
- `请选择一个视频`
- `请先在 API 设置中配置 MediaKit Key`
- `保存目录不可写`

## 6. 结果节点与画布行为

### 6.1 创建时机

点击“开始增强”后先完成本地预检：

- API Key 是否存在
- 保存目录是否可写
- 输入格式和分辨率
- SDR/HDR
- 参数范围

预检通过后，在增强节点右侧立即创建标准 `smart-image` 结果节点，并连接：

```text
增强节点 → 结果节点
```

结果节点初始显示现有等待骨架和运行计时。预检失败时不创建空结果节点，也不提交远端任务。

### 6.2 布局

结果节点复用 `nextOutputPositionForSource()` 的现有右侧排列策略：

- 水平间距沿用智能画布输出节点间距
- 同一增强节点多次运行时结果向下顺排
- 不覆盖已有节点

### 6.3 状态展示

结果节点复用现有状态：

- 提交中：等待骨架
- 排队/处理中：等待骨架、计时药丸、动态连线
- 完成：显示普通视频卡片
- 失败：显示错误摘要与“重新查询”或“重新增强”

远端 `task_id`、请求参数和输出保存状态存放在结果节点的任务元数据中。保存画布后刷新页面或重启应用，仍能继续查询未完成任务。

## 7. 普通画布节点设计

### 7.1 节点类型与原生外观

新增普通画布节点类型：

```text
mediakitEnhance
```

节点名称显示为 `MediaKit 画质增强`，使用普通画布现有生成类节点外壳：

- 使用 `.node`、`.node-head`、`.node-title` 和 `.node-body`
- 参数主体使用 `.generator-body`、`.gen-settings` 和 `.gen-settings-row`
- 主按钮使用 `.gen-btn`
- 使用普通画布的左侧输入端口、右侧输出端口和连线规则
- 使用现有 `.node-run-status`、失败徽章和 `.node-retry-bar`
- 右键端口菜单、删除、选择、拖动、缩放和画布保存行为与其他普通画布生成节点一致

建议宽度与现有 Video/API 生成节点一致，由 `defaultNodeSize()` 统一管理，不引入智能画布的浮动工具栏或卡片 CSS。

### 7.2 节点内容

从上到下排列：

1. 上游视频输入
   - 复用普通画布现有媒体输入预览/列表样式
   - 一个视频时直接选中
   - 上游 Output 含多个视频时显示视频选择列表，并持久化所选媒体索引
2. 目标分辨率
   - 普通画布分段按钮：720P / 1080P / 2K
3. 码率档位
   - 普通画布分段按钮：低码率 / 中码率 / 高码率
4. 目标帧率
   - 普通数字输入框，留空表示保持原帧率
   - 有值时限制为 15–120
5. 主操作按钮
   - 默认：`开始增强`
   - 运行：`处理中`
   - 可重新提交：`重新增强`

默认值与智能画布相同：`720p + medium + 不传 fps`。

### 7.3 创建入口与连接菜单

节点提供以下入口：

1. 普通画布空白处的现有创建菜单增加 `MediaKit 画质增强`。
2. 从包含视频的上传节点、Output 节点或视频生成类节点拖出连线时，现有连接创建菜单增加 `MediaKit 画质增强`。
3. 普通画布生成类节点的右键输出菜单，在该节点能够产生视频时增加 `MediaKit 画质增强`。

从连线菜单创建时，节点按现有 `createLinkedNode()` 规则自动创建并连接，不实现另一套菜单或定位逻辑。

### 7.4 连接与输入规则

- 增强节点只接受一个上游连接。
- 上游必须能解析出至少一个视频；图片、音频、Prompt 或纯文本连接无效。
- 上传视频节点可直接连接增强节点。
- 视频生成节点可直接连接增强节点。
- 普通 Output 节点可连接增强节点；当 Output 中有多个视频时由用户在增强节点内选择一个。
- 增强节点可连接普通 Output 节点，也可连接下游能消费视频的普通画布生成节点。
- 连接合法性加入现有 `canConnect()` 与循环检测，不绕过普通画布连接校验。

节点运行时通过现有 `generatorSources()` 和 `orderedSources()` 解析上游媒体，使手动运行与一键运行使用同一输入顺序。

### 7.5 手动运行、Output 与一键工作流

点击节点内 `开始增强` 后才执行：

1. 完成 Key、目录、格式、尺寸、SDR/HDR 和参数预检
2. 使用现有 `outputForNode()` 在右侧取得或创建标准普通 `Output` 节点
3. 在 Output 节点中加入普通画布现有的视频等待项
4. 提交 MediaKit 任务并更新节点运行状态
5. 完成后向 Output 写入 `{ url, kind: "video" }` 结果

预检失败时不创建空 Output 结果、不提交任务。

`mediakitEnhance` 加入普通画布现有运行类型、媒体输出类型和级联执行分派。因此以下链路既可以单独点击增强节点运行，也可以使用普通画布现有一键运行能力串行执行：

```text
视频生成节点 → MediaKit 画质增强 → Output
```

一键运行时，上游视频生成完成后才开始增强；普通连接操作本身不自动提交增强任务。

### 7.6 状态、恢复与数据兼容

- 节点状态使用普通画布现有 `queued / running / done / failed` 展示。
- Output 等待项、任务轮询和刷新恢复复用普通画布现有 pending 结果机制。
- 远端任务成功但本地保存失败时，Output 显示可重试保存状态；重试保存不重新提交付费任务。
- 节点参数和所选视频索引随普通画布 JSON 保存。
- 旧画布没有 `mediakitEnhance` 节点时行为不变。

## 8. API 设置设计

### 8.1 独立固定卡片

在 API 设置的平台列表中增加固定卡片：

```text
名称：AI MediaKit
协议标签：MediaKit
服务地址：https://mediakit.cn-beijing.volces.com
```

卡片与 ModelScope、RunningHub、火山引擎一样不可删除，视觉上沿用现有平台卡片规则。

### 8.2 Key 配置

字段与行为：

- 密码输入框
- 保存 Key
- 清除 Key
- 已保存状态和末四位预览
- 获取 Key 链接：
  `https://console.volcengine.com/imp/ai-mediakit/settings`

后端保存：

```text
文件：API/.env
变量：MEDIAKIT_API_KEY
```

GET 接口只返回：

- `has_key`
- `key_preview`

任何 API 响应、画布 JSON、日志或错误信息都不得包含 Key 明文。

### 8.3 保存位置

MediaKit 卡片内增加：

- `跟随生成素材目录` 开关，默认开启
- 当前解析后的实际目录
- 自定义绝对路径输入框
- 保存设置按钮
- 打开当前目录按钮

继承模式的实际目录：

```text
{当前生成素材目录}\mediakit-enhance
```

自定义模式使用用户提供的绝对路径。

保存时后端执行：

- 解析并规范化绝对路径
- 创建不存在的目录
- 检查目录是否可写
- 返回规范化后的实际路径

非密钥设置保存在：

```text
data/mediakit_settings.json
```

建议结构：

```json
{
  "inherit_generated_dir": true,
  "output_dir": ""
}
```

Key 不写入该 JSON。

### 8.4 建议后端接口

```text
GET   /api/mediakit/settings
PATCH /api/mediakit/settings
POST  /api/mediakit/open-output-dir
```

`PATCH` 支持：

- 保存或清除 Key
- 更新继承开关
- 更新自定义目录

## 9. 后端任务流程

### 9.1 应用内部接口

建议增加：

```text
POST /api/mediakit/enhance-tasks
GET  /api/mediakit/enhance-tasks/{task_id}
POST /api/mediakit/enhance-tasks/{task_id}/retry-save
```

提交请求示例：

```json
{
  "video": {
    "url": "/assets/output/example.mp4",
    "name": "example.mp4"
  },
  "resolution": "720p",
  "bitrate_level": "medium",
  "fps": null,
  "client_token": "canvas-surface-node-task-id",
  "canvas_surface": "smart"
}
```

`canvas_surface` 允许值为 `smart` 或 `standard`，仅用于恢复任务时路由到正确画布，不影响 MediaKit 官方请求。

### 9.2 输入解析与上传

输入按来源分流：

- 公网 HTTP/HTTPS 地址：可直接提交时使用原地址
- 本机相对 URL、localhost URL、本地文件：先通过 MediaKit 上传流程转换为 `mediakit://...`
- VOD/TOS/MediaKit 地址：按官方协议原样提交

上传和提交全部在后端完成，浏览器不接触 API Key。

### 9.3 幂等

- 首次运行生成稳定 `client_token`
- 网络重试复用同一 `client_token`
- 用户明确点击“重新增强”时生成新 `client_token`
- `client_token` 不超过 64 个可打印 ASCII 字符

### 9.4 查询与持久化

建议把任务记录保存到：

```text
data/mediakit_tasks.json
```

记录至少包含：

- 本地任务 ID
- 远端任务 ID
- 画布类型、画布 ID、增强节点 ID、结果节点 ID
- 请求参数
- 输入媒体信息
- 当前状态
- 错误信息
- 远端结果 URL 与到期时间
- 本地保存路径
- 创建、完成时间

前端使用现有轮询方式更新结果节点。页面关闭不会影响远端任务；重新打开画布时根据任务记录继续查询。

### 9.5 下载与本地保存

任务完成后：

1. 流式下载到目标目录中的 `.part` 临时文件
2. 下载完成后原子重命名为 `.mp4`
3. 把文件登记到现有生成素材/资产体系
4. 返回可由智能画布和普通画布长期访问的本地 URL
5. 把本地 URL 写入结果节点

文件名：

```text
mediakit-enhance_YYYYMMDD_HHMMSS_{task_id短码}.mp4
```

如果远端任务完成但本地保存失败：

- 保留远端 URL 和到期时间
- 结果节点显示“增强完成，保存失败”
- 提供“重新保存”动作
- 不重新提交付费增强任务

## 10. 错误处理

### 10.1 提交前错误

以下错误在远端提交前拦截：

- 未配置 Key
- 保存目录无效或不可写
- 没有视频输入
- 输入尺寸超限
- 明确检测为 HDR
- 分辨率、码率或帧率参数非法

### 10.2 远端错误

显示 MediaKit 返回的可读错误，同时隐藏可能包含敏感信息的 Header、Key 或完整本地路径。

常见状态：

- 认证失败：引导到 API 设置
- 输入地址不可下载：提示重新上传/检查源视频
- 参数拒绝：标记具体字段
- 任务处理失败：保留远端任务 ID 便于排查

### 10.3 恢复规则

- 已有远端任务 ID：只重新查询，不重复提交
- 已有成功结果但未保存：只重试下载
- 明确点击重新增强：创建新的付费任务和新的结果节点

## 11. 安全与路径规则

- API Key 仅存在于服务端环境文件和请求 Header。
- 日志不得打印 `Authorization`。
- 自定义保存路径必须规范化为绝对路径。
- 文件名只使用安全字符，禁止从远端文件名拼接目录片段。
- 下载使用临时文件，避免中断后留下伪完成文件。
- 打开目录只能打开当前已保存且验证通过的目录。
- 画布删除节点不自动删除磁盘上的增强视频，遵循现有素材保留规则。

## 12. 国际化与兼容

- 新增中文和英文 i18n 文案。
- 亮色和暗色主题都必须使用现有 CSS 变量。
- 不改变既有节点和旧画布数据格式。
- 未识别 `smart-video-enhance` 的旧版本应忽略专用字段，不影响其他节点。
- 未识别 `mediakitEnhance` 的旧版本不应破坏其他普通画布节点数据。
- 智能画布与普通画布只共享后端能力，不互相复用节点 DOM 或样式。

## 14. 验收标准

### 14.1 API 设置

- 能保存、掩码显示和清除 MediaKit Key。
- MediaKit Key 与 Ark Key 完全独立。
- 能在继承目录和自定义目录之间切换。
- 不可写目录会在保存或运行前明确报错。
- 智能画布和普通画布读取同一份 Key 与保存目录设置。

### 14.2 智能画布

- 能从创建菜单新建增强节点。
- 能从单个视频的浮动工具栏一键创建并连接增强节点。
- 连接关系显示为“视频 → 增强 → 结果”。
- 非视频节点不能作为有效输入。
- 多视频上游可在节点内选择具体视频。
- 默认请求实际发送 `720p + medium`，且不发送 `fps`。

### 14.3 普通画布

- 能从普通画布创建菜单新建 `MediaKit 画质增强` 节点。
- 能从上传视频、视频生成节点或含视频的 Output 连接创建增强节点。
- 节点外观、端口、参数控件、运行状态和失败重试符合普通画布现有节点规则。
- 非视频来源不能有效连接或运行。
- Output 含多个视频时可在增强节点内选择一个视频。
- 点击 `开始增强` 后才提交任务并创建或复用普通 Output 节点。
- 完成结果以普通视频项写入 Output，并加入现有素材体系。
- 默认请求实际发送 `720p + medium`，且不发送 `fps`。
- `视频生成 → MediaKit 画质增强 → Output` 可以按现有普通画布一键运行顺序执行。
- 仅创建或连接节点不会自动提交付费任务。

### 14.4 输入检查

- 普通 BT.709 SDR 视频可以提交。
- 明确的 PQ、HLG 或 Dolby Vision 视频在远端提交前被拦截。
- 超过官方输入尺寸限制的视频在远端提交前被拦截。

### 14.5 任务与结果

- 点击开始后创建新的等待结果节点，原视频不改变。
- 页面刷新或应用重启后能继续查询任务。
- 任务完成后视频保存到配置目录并写入结果节点。
- 远端临时 URL 过期后，本地结果仍可播放。
- 下载失败可以只重试保存，不重复产生增强费用。

### 14.6 回归

- 现有 Seedance 480p 选择不受影响。
- Prompt、Loop、Group、图片/视频节点的创建和连线不受影响。
- 普通画布既有生成节点、Output 节点和一键运行顺序不受影响。
- 现有 API 平台的 Key 保存和 Provider 顺序不受影响。
- 现有生成素材目录设置继续生效。

## 15. 非目标

首版不包括：

- 标准版、专业版或极速版画质增强
- HDR 转 SDR
- 未由用户点击增强按钮或主动启动一键工作流时，视频生成结束后自动提交增强
- 每个节点单独选择磁盘目录
- VOD/TOS 产物存储配置
- 批量增强多个上游视频
