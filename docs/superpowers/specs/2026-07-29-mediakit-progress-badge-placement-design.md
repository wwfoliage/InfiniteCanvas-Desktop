# MediaKit 画质增强计时徽标位置设计

## 目标

智能画布执行 MediaKit 画质增强时，只在新建的增强结果节点右上角显示运行秒数。画质增强参数节点右上角不再重复显示秒数。

## 界面规则

- `smart-video-enhance` 画质增强节点：
  - 不渲染通用 `run-time-pill` 秒数徽标。
  - 保留节点内部“MediaKit 正在增强视频”状态。
  - 保留底部“增强中”按钮状态。
- 增强后结果节点：
  - 继续显示右上角运行秒数。
  - 任务成功或失败后沿用现有完成状态。
- 其他智能画布节点：
  - 现有运行秒数显示规则不变。

## 实现方案

在智能画布通用计时徽标入口 `runTimePillHtml(node)` 中，显式排除 `node.type === 'smart-video-enhance'`。不删除或修改 `runStartedAt`、`runFinishedAt` 等任务时间字段，确保任务恢复、日志和结果节点计时不受影响。

不采用纯 CSS 隐藏，因为渲染层排除能避免生成无用 DOM，也能更明确地表达产品规则。

## 验收

1. 启动增强任务后，画质增强节点右上角没有秒数徽标。
2. 增强后结果节点右上角正常显示并刷新秒数。
3. 画质增强节点内部仍显示进行中状态，按钮仍为“增强中”。
4. 其他生成节点的计时徽标行为不变。
