# InfiniteCanvas 白天模式“暖米灰”统一主题设计

## 目标

将 InfiniteCanvas 的白天模式统一为已确认的“暖米灰”方案，降低大面积近纯白背景带来的刺眼感，同时保持节点、控件、连线和状态信息清晰可辨。

本次只调整白天模式的视觉配色。深色模式、页面布局、节点行为、生成流程和媒体内容保持不变。

## 适用范围

统一调整以下页面的白天模式：

- 智能画布
- 普通画布
- 画布列表
- API 设置
- 素材库
- 首页及共享主题样式覆盖的工具页面，包括角度、增强、对话、在线生成、Klein 和 Z-Image 页面

## 不在范围内

- 不修改深色模式配色
- 不增加第三套主题或新的主题切换入口
- 不调整节点尺寸、位置、连线逻辑、布局或交互
- 不改变图片、视频和预览素材的像素颜色
- 不修改生成 API、MediaKit、Seedance 2.0 或保存路径逻辑

## 统一色板

| 语义 | 颜色 | 用途 |
|---|---|---|
| 页面/画布背景 | `#E0DDD4` | 大面积画布和页面底色 |
| 侧栏背景 | `#E9E5DC` | 左侧导航和固定工具栏 |
| 面板背景 | `#EFECE5` | 浮层、设置区和工具面板 |
| 节点/卡片背景 | `#F3F0E9` | 节点、卡片和输入容器 |
| 次级背景 | `#E5E0D7` | 悬停、分组、禁用和次级区域 |
| 主边框/连线 | `#C5BEB2` | 卡片边框、输入框和普通连线 |
| 强边框 | `#B0A89B` | 选中、聚焦和层级分隔 |
| 网格点 | `rgba(183,174,161,.55)` | 画布背景网格 |
| 主文字 | `#3B3935` | 标题、正文和主要图标 |
| 次文字 | `#746F66` | 描述、标签和辅助信息 |
| 弱文字 | `#928A7E` | 占位符和弱提示 |
| 强调色 | `#786B5C` | 普通激活和强调控件 |
| 主操作色 | `#625548` | 主按钮和选中状态 |
| 主操作文字 | `#F7F4EE` | 深色主按钮上的文字 |
| 阴影 | `rgba(73,64,54,.10)` | 轻量层级阴影 |

错误、警告、成功和处理中状态继续使用原有语义色，但降低背景饱和度，确保状态含义不会因暖米灰主题而丢失。

## 实现方案

### 页面级主题变量

在以下样式文件中调整白天模式的根变量，不改动对应的深色模式选择器：

- `static/css/smart-canvas.css`
- `static/css/canvas.css`
- `static/css/canvas-list.css`
- `static/css/asset-manager.css`
- `static/css/api-settings.css`

API 设置样式包含多个历史变量块，以文件末尾的最终统一变量块为准，避免扩大改动范围或进行无关重构。

### 共享页面覆盖

在 `static/css/theme.css` 中增加仅对白天模式生效的暖米灰共享变量和组件级覆盖，用于首页及采用共享主题的工具页面。

覆盖应限定在应用外壳、面板、卡片、输入控件、按钮和常见浅色工具类，不使用面向所有元素的全局背景覆盖，也不对 `img`、`video`、媒体画布或预览内容应用滤镜和透明叠层。

### 主题切换

保留 `static/js/theme.js` 的现有主题存储和切换逻辑：

- `light` 继续表示白天模式
- `dark` 继续表示深色模式
- 不迁移或清除用户现有的 `studio_theme` 设置
- 切换主题和刷新页面后仍应保持用户选择

### 浏览器缓存

更新受影响 HTML 页面中相关 CSS 的版本查询参数，使其他电脑替换文件后无需清理全部浏览器数据即可加载新配色。

## UI 规则

- 大面积区域不得继续使用纯白 `#FFFFFF` 或接近纯白的背景。
- 节点和卡片必须比画布背景亮一个层级，但不能形成强烈白色发光感。
- 主按钮由纯黑改为暖深灰棕，保持清晰但降低刺激。
- 网格点和连线在缩放后仍应可见，且不能比节点边框更抢眼。
- 图片、视频和预览缩略图保持原始颜色，不增加暖色滤镜。
- 选中、悬停和聚焦状态同时依赖颜色与边框变化，不能只靠阴影。
- 错误和成功状态保持原有语义，不统一改成棕色。

## 兼容与风险控制

- 深色模式的变量和最终视觉不得发生变化。
- 页面中存在硬编码浅色值时，只对明确的 UI 容器增加白天模式覆盖，避免误改媒体内容。
- API 设置页存在多个历史覆盖块，实施时只修改最终生效层并通过计算样式确认结果。
- 用户工作区已有其他未提交改动，实施和提交时只包含本主题相关文件，不覆盖或回滚现有修改。

## 验证

1. 智能画布、普通画布、画布列表、API 设置和素材库均显示一致的暖米灰白天模式。
2. 大面积画布背景使用 `#E0DDD4`，节点和卡片使用 `#F3F0E9` 或对应的半透明等价值。
3. 主要文字与卡片背景的对比度达到 WCAG AA 正文要求；次要文字保持清晰可读。
4. 图片和视频缩略图颜色与修改前一致。
5. 网格、连线、边框、输入框、按钮和选中状态均可辨识。
6. 白天模式与深色模式可正常切换，刷新后主题设置保持。
7. 深色模式关键页面截图与修改前无视觉回归。
8. 浏览器强制刷新和普通刷新均能加载新样式。
9. 运行现有自动化测试，并增加对白天模式关键色板和深色模式变量保持不变的静态检查。
